# Telegram demo bot

Локальный бот использует long polling, поэтому Telegram не должен обращаться к вашему компьютеру напрямую. Он проверяет, начал ли клиент диалог через `/start`, показывает вступительное сообщение, задаёт 5 уточняющих вопросов и отправляет одну собранную заявку в локальный webhook n8n.

## Запуск

1. Не отправляйте токен в Git или чат. Создайте локальный файл `.env` по образцу `.env.example`.
2. В одном терминале запустите n8n и включите workflow с webhook `telegram-lead`.
3. Во втором терминале в этой папке выполните:

```bash
set -a; source .env; set +a; node index.mjs
```

4. Отправьте боту `/start` и ответьте на вопросы. Повторный `/start` начинает анкету заново.

При выключенном компьютере или остановленном процессе бот не отвечает. Состояние незавершённой анкеты пока хранится в памяти процесса: при перезапуске клиенту нужно заново отправить `/start`. Для production-версии состояние нужно перенести в Redis/БД, а процесс и n8n — на сервер.
