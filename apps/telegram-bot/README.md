# Telegram demo bot

Локальный бот использует long polling, поэтому Telegram не должен обращаться к вашему компьютеру напрямую. Бот получает сообщение, отправляет заявку в локальный webhook n8n и подтверждает приём клиенту.

## Запуск

1. Не отправляйте токен в Git или чат. Создайте локальный файл `.env` по образцу `.env.example`.
2. В одном терминале запустите n8n и включите workflow с webhook `telegram-lead`.
3. Во втором терминале в этой папке выполните:

```bash
set -a; source .env; set +a; node index.mjs
```

4. Напишите обычное текстовое сообщение боту.

При выключенном компьютере или остановленном процессе бот не отвечает. Для production-версии этот процесс и n8n переносятся на сервер.
