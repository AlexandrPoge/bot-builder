# Настройка Google Sheets

## 1. Создайте рабочую таблицу

1. Откройте Google Sheets и создайте таблицу `Lead Automation Lab`.
2. Создайте три листа с точными именами: `Leads`, `Events`, `Metrics`.
3. Импортируйте в каждый лист одноимённый CSV-файл из папки `sheets/`.
4. Зафиксируйте первую строку (View → Freeze → 1 row).

Не меняйте названия колонок: n8n будет сопоставлять их с полями workflow.

## 2. Подключите Google Sheets в n8n

1. В **Credentials** создайте credential типа **Google Sheets OAuth2 API**.
2. Войдите в Google-аккаунт, который владеет таблицей.
3. Назовите credential `sheets-main`.
4. В workflow `01 · Lead intake foundation` после `Normalize lead` добавьте узел **Google Sheets**.
5. Выберите действие **Append Row**, документ `Lead Automation Lab`, лист `Leads`.
6. Включите ручное сопоставление колонок и передайте поля с теми же именами из входного JSON.

Минимально обязательные поля для первой записи: `lead_id`, `created_at`, `source`, `contact`, `raw_text`, `status`.

## 3. Проверка

Запустите workflow вручную. В листе `Leads` должна появиться ровно одна новая строка. Если узел падает, не пробуйте повторно много раз: сначала посмотрите входные данные узла и текст ошибки.

## Что пока не автоматизировано

Проверка дублей и логирование Events появятся следующим этапом. Сейчас цель — научиться безопасно передавать нормализованную заявку в таблицу.
