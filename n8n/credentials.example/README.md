# Подключения n8n

Создавайте credentials только внутри n8n. Не храните API-ключи в этом репозитории.

- `Telegram Bot API` — входящие сообщения и уведомления.
- `Google Sheets OAuth2` — Leads, Events, Metrics.
- `Gemini API` — учебный этап.
- `OpenAI API` — этап внедрения.

Имена credentials лучше оставить неизменными при миграции: `ai-primary`, `sheets-main`, `telegram-main`.
